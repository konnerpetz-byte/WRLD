# WRLD: Send seats to WRLD

A one-button browser extension. On an airline's award search results, click it to send the
dates, points prices and taxes you see to the WRLD points explorer, where you confirm them.

- Permissions: `activeTab` and `scripting` only. It can read a page only when you click the button on it.
- No background activity, no host permissions, no tracking. It never searches airline sites by itself.

Install (Chrome, Edge, Brave): open `chrome://extensions`, turn on Developer mode, choose
"Load unpacked" and pick this folder. It can also be published for free on Microsoft Edge Add-ons.
